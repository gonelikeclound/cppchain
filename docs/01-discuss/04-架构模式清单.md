# 04 · 架构模式清单

> Agent 开发的架构模式清单。`04-problems/07`、`04-problems/08` 的架构实验，
> 以及 `examples/agent_cli`、`examples/research_chat` 的设计，都以此为参照。

- Single-Agent
- ReAct 架构
- Plan-and-Execute
- Multi-Agent
- Router + Skill
- Blackboard
- Graph Workflow

## 对照落地（各模式在本项目里由哪个 demo 承载）

| 模式 | 承载 |
|---|---|
| Single-Agent | `agent_loop` |
| ReAct | `agent_cli --mode react` |
| Plan-and-Execute | `subagent_workers`（supervisor 先拆任务再分发） |
| Multi-Agent | `subagent_ask_expert` / `subagent_workers` / `subagent_handoff` |
| Router + Skill | `research_chat`、`agent_cli --mode direct` |
| Blackboard | 未单独成 demo；`StateGraph` 的共享 state 即其形态 |
| Graph Workflow | `graph_basics`、主动智能 `workflow`（IR → 图） |
