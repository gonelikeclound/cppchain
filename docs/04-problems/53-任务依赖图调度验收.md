| 件 | 内容 |

| 同上 · 模型档 | 简报每任务带 `依赖:[…]`；缺省 prompt 加"只能选依赖就绪（deps 全部 done）的任务，依赖未就绪不可选"；模型选未就绪 → 拒绝回落规则档；`task=null & done=false`（依赖阻塞）与 `done=true` 区分文案 |
| 同上 · 结果 | 新槽 `blocked` / `ready`（就绪数）；**`done` 语义修正** = 停机 且 非依赖阻塞（阻塞 ≠ 完成） |
| 测试 | `project_drive_test.cpp` +6（见 §二）；demo `weekly.deps=["monthly"]` 演示依赖门 |

### 关键语义

1. **依赖 = 就绪门，不是排序**：规则档仍在就绪任务里做经验加权；依赖只决定"谁够资格入选"。
2. **阻塞停机 ≠ 完成**：`done=false`（有未完成但无就绪）——区分"项目做完了"与"做不下去了"；gate 照常
   `_break`（`next_task=null`），loop 不死循环（loop max 兜底仍在）。
3. **模型档 fail-closed**：模型可以自由挑就绪任务，但选到未就绪/环依赖 → 拒绝并回落规则档。
