## 一、设计：组合的**顺序**才是变量

组合不是"1+1" —— 两个节点的**先后**决定了截然不同的结果：

| 臂 | 图 | 说明 |
|---|---|---|
| `full` | `recall → loop` | 全量基线（不处理） |
| `sum` | `recall → sum → loop` | 只摘要（`style=evidence`） |
| `rules` | `recall → refine → loop` | 只精简（aggressive + 丢 retrieval 类工具轮） |
| **`sr`** | `recall → sum → refine → loop` | **先摘要 → 后精简**：先把历史折成摘要（保住事实与来源），再删掉剩下的检索轮 |
| **`rs`** | `recall → refine → sum → loop` | **先精简 → 后摘要**：先用规则把检索轮删掉，再摘要剩下的 |

新增两个内置 workflow：`hist_both`（sr）与 `hist_rules_sum`（rs）。

## 二、结果速查

| 臂 | 条数 | 对话 prompt token | 摘要调用 | 回答字数 | 回答质量 |
|---|---|---|---|---|---|
| `full` | 24 → 24 | 76248 | — | 744 | 完整 + 来源齐全 |
| `sum` | 24 → 8 | 35958 | 1954 tok | 775 | 完整 + 来源齐全 |
| `rules` | 24 → 6 | **10728** | **0（不需要）** | 508 | **第 3 项"暂无结果"**（那条检索轮被删了） |
| **`sr`** | 24 → **2** | **2028** | 1978 tok | **956** | **最详细 + 来源清单最长** |
| **`rs`** | 24 → 6 | 10728 | **0** | 530 | **开头就声明"不能当作已核实的数据"** |

**两条结论（组合的顺序决定成败）**：

1. **`sr`（先摘要后精简）= 最好**：prompt 只有 **2028 tok**（比 `rules` 的 10728 少 5 倍），
   回答却**最长最详细**，来源清单也最长（新华社、新华网、科技日报、中国科技网、澎湃新闻、
   科学网、新民晚报、北京日报、每日经济新闻）—— 因为摘要（`evidence` 档，1978 tok）已经把
   事实与**来源**固化了，之后再把剩下的检索轮删掉也不损失什么。
2. **`rs`（先精简后摘要）= 最差**：规则先把 6 组检索轮删光，剩下的历史只有 6 条 →
   **摘要无事可做（折叠 0、0 token）**，于是**既没省下摘要调用，又丢掉了全部凭据**。
   模型的开场白就是证据：

   > 三件事的要点如下，但先说一句要紧的话：**这三条里只有前两条我"说过"，而它们并没有对应的
   > 检索结果留痕**（没有工具调用记录、没有可点开的来源链接），第三条**根本没查过**。所以下面的
   > 内容只能算"我当时给出的说法"，**不能当作已核实的数据**。

   同一个模型、同一份历史、同一个问题 —— 只因为**先删了证据**，它就拒绝为自己的回答背书。
   这是 wfr-㉙「模型否认自己查过」的**放大版**（那次是温和的降级，这次是开篇免责声明）。

**推论**：`drop_category:retrieval` 这类"删掉整轮检索"的规则，**必须排在摘要之后**
（或者干脆别用）。它的收益（省 token）在长内容上很可观，但它删掉的恰好是**凭据**。

## 四、数据来源与复现

```bash
# 0) 直接用实验 C 的原始历史（复制，不动原件）
mkdir -p tmp/wfr-combo/.wfr/sessions
cp tmp/wfr-web/.wfr/sessions/session-base.log.jsonl tmp/wfr-combo/.wfr/sessions/
cd tmp/wfr-combo/.wfr/sessions
for s in full sum rules sr rs; do cp session-base.log.jsonl session-$s.log.jsonl; done

# 1) 五个臂，同一句追问
Q="把前面查到的三件事的关键信息列出来：每件事的关键人物或数字、以及信息来源，不要重新查"
S="--set sum_when=always --set sum_style=evidence"
R="--set rule_preset=aggressive --set drop_categories=retrieval"
W="--workdir tmp/wfr-combo"
./wfr.sh hist_sum       $W --session full  --set sum_when=off "$Q"
./wfr.sh hist_sum       $W --session sum   $S "$Q"
./wfr.sh hist_rules     $W --session rules $R "$Q"
./wfr.sh hist_both      $W --session sr    $S $R "$Q"      # 先摘要 → 后精简
./wfr.sh hist_rules_sum $W --session rs    $S $R "$Q"      # 先精简 → 后摘要

# 2) 调试台并排（能看到两个 op 的顺序）
./wfr.sh debug hist_both --workdir tmp/wfr-combo --all --open
```
