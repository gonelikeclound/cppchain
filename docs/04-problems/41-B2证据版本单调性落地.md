# 41 · B2 证据版本单调性落地

> **链路**：[discuss 19](../01-discuss/19-Agent执行治理-跨系统优点提取.md) B2（版本单调性替代时间戳：
> "新鲜度判据写成 evidence.version ≥ 目标文件的最后写入版本；版本号由服务分配，模型伪造不了"）
> → [problems/39](39-治理手册对照评估与A6验收规划.md) 优先级 2 → 本落地。

## 一、问题与决策

### 现状
verify probe 判据只判"文件存在/内容对"，无新鲜度概念；若靠 mtime 不可靠（工具可 touch 伪造"新鲜"）。
B2 目标：verify 判据可声明 `version`，宿主给每次产物写入分配**单调版本号**（模型/工具伪造不了），
probe 校验 `目标文件当前版本 ≥ 判据声明版本`。

### 已确认（Explore）
- 版本源 = 引擎全局原子 `g_artifact_ver`（`next_artifact_version()`，`++` 单调；跨 fire/节点严格递增）。
- 存储 = state 新键 `_artifact_ver`（merge_slots，照抄 `_tool_loop` 范式）；task 档案 begin/end 快照恢复。
- 登记 = 节点层（c_tool/c_run_tools）在执行**成功**后，从 `call.args.path`（file_write 的 schema 参数，
  相对沙箱根串）登记——**不依赖 handler 返回**（run_tools 路径返回被 dump 成字符串也拿得到）。
- 校验 = `verify_rule_check` probe 分支；不新鲜映射 **Partial**（fail-closed，无新枚举格）。
- 版本号**绝不出现在 handler 内部**（模型/工具伪造不了）。

### 一个设计修正（实现中决定）
初稿打算给 ToolContext 注入 registrar（改 tool 层）——但 run_tools/guard 路径把 handler 返回值
dump 成 ToolMessage 字符串，靠 result 拿不到 path。**改在节点层用 `call.args.path` 登记**
（file_write 的 args 就是相对沙箱根串，模型调它必然带），零 tool 层改动，且覆盖 guard 路径。

## 二、实现

### 1. 版本源（compiler.cpp）
```cpp
std::atomic<std::int64_t> g_artifact_ver{0};
std::int64_t next_artifact_version() { return ++g_artifact_ver; }  // 公开，节点层取号
```
声明进 `compiler.hpp`（与 seed_run_seq 同源区域）。

### 2. state 键 + schema
- `refs.hpp` 加 `kArtifactVerKey = "_artifact_ver"`；
- `compiler.cpp` schema 加 `set_reducer(kArtifactVerKey, merge_slots)`（子键右胜）。

### 3. 节点层登记（node_types.cpp）
helper：
```cpp
void b2_register_artifact(Json& update, Json const& call_args, bool ok) {
  if (!ok || !call_args.is_object() || !call_args.contains("path") ||
      !call_args["path"].is_string()) return;
  Json ver = update.contains(kArtifactVerKey) ? update[kArtifactVerKey] : Json::object();
  ver[call_args["path"].get<std::string>()] = next_artifact_version();
  update[kArtifactVerKey] = std::move(ver);
}
std::int64_t b2_artifact_version(Json const& state, std::string const& relpath) { /* -1 缺省 */ }
```
- `c_tool`：`if (r) { ...; b2_register_artifact(update, args, true); }`
- `c_run_tools`：update 构造后，遍历 `all_calls[i]` + `tool_msgs[i]`，`status=="success"` → 登记。

### 4. verify_rule_check 校验（node_types.cpp probe 分支）
文件内容完整（ProbeResult::Complete）后、return true 前：
```cpp
if (v.contains("version") && v["version"].is_number_unsigned()) {
  std::int64_t const have = b2_artifact_version(state, p);  // 未登记 → -1
  std::int64_t const want = v["version"].get<std::int64_t>();
  if (have < want) {
    why = "probe=Partial：路径 " + p + "（版本 " + std::to_string(have) + " < 要求 " +
          std::to_string(want) + "）——证据过时";
    return false;
  }
}
```

### 5. task 档案快照/恢复（node_types.cpp task begin/end）
- begin：档案含 `artifact_versions` → 塞回 `update[kArtifactVerKey]`（跨 run 续跑保持单调）；
- end：`plan2["artifact_versions"] = state[kArtifactVerKey]` 写档。

## 三、测试（tests/wf/artifact_ver_test.cpp 6 例）

| 测试 | 场景 | 断言 |
|---|---|---|
| `version_match_advances` | file_write 写 → version 判据 0（≤ 实际）| `_artifact_ver[path]>0`、cursor=1、done |
| `version_stale_fails` | 先写，判据 version=999999 | cursor=0、failed、verdict=fail、why 含 Partial+证据过时 |
| `version_unregistered_fails` | 没写工具，判据 version=1 | fail（have=-1 < 1）|
| `no_version_zero_regression` | 旧判据无 version | done（行为不变）|
| `versions_monotonic_across_fires` | 两次 fire 写同 path（独立 thread）| v2 > v1（引擎单调）|
| `run_tools_registers_artifact` | 模型调 file_write（走 run_tools）| `_artifact_ver[path]>0` |

**测试逼出的点**：stale/monotonic 的两次 fire 若共用 thread_id，第二次从 checkpoint 续跑
（同 call id "c1" 被 done_ids 过滤 → file_write 不执行、版本不涨）——**独立 thread 才测"跨 fire 单调"**
（每次全新 state）。记录为测试纪律。

## 四、边界 / 已知限制

- **登记覆盖 c_tool + run_tools**；`executor`（并行复合）暂未登记（多轮结构，非 B2 主线；
  若需可在 executor 工具执行段同款加）。
- **submit_result**（trip_db）写 `.out/trip_verdict.json` 是 cwd 相对、args 无 path——不在此登记；
  需要时先归一到 workspace 相对串再登记。
- **跨 fire 单调依赖 `g_artifact_ver` 全局原子 + `_artifact_ver` 表 max 语义**（merge_slots 不删旧 path，
  续跑恢复旧值）；`task` 档案快照保证跨进程续跑不丢版本表。
- **新鲜度映射 Partial**（证据在但过时，fail-closed），与"内容不匹配"同档；未登记 = -1 = 过时。

## 五、结果

- 全仓 **781 全绿**（775 基线 + 6 新）。
- verify 现在能校验"产物新鲜度"：判据声明 version，版本号由引擎分配（模型/工具伪造不了），
  过时产物 fail-closed 拒绝——A9 的正解落地（替代 mtime）。
