## 二、真机实证

- **continue 连走两边界**：`0/2 → [continue] → 1/2 → [continue] → 完成`（每步边界都停下来给人裁决）。
- **rollback_to**（单测驱动的回退序列）：s1 完成后在 s2 边界 `rollback_to 0` → cursor 归 0、s1 重新 pending、plan_log 落 rollback 事件、重做完 cursor=1 s1 done。
- **节点级 abort**（mock deny 触发）：`plan.aborted=true`、steps 全 `aborted`、plan_log `{action:abort}`、会话 2 条（无多余模型调用）。
- CLI `abort` 输入 = 宿主停（留待续审），与节点 abort 语义分离、各有一方留痕。

## 三、遗留 / 边界

- `rollback_to:K` 的**副作用清理**依赖既有快照/沙箱（本轮只做状态指针+审计，不试着"反做命令"，见 06 §7 L7）。
- 回退的**裁量权**目前全在确认门（人/mock），`strategy.on_fail` 的自动回退（验证失败→自动回第 K 步）未做——留给后续。
- 计划**中途编辑**未做（编辑=重规划，见 arch 19 §一③）。
