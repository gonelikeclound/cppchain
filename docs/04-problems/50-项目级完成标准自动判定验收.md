### 关键语义

1. **复用批级终审纪律，输入换成项目简报**：Reviewer 只见「目标 + 验收标准 + 纪律 + 各任务进度/摘要」，
   不投单任务执行思考（与 judge_batch_review 同款输入隔离）。
2. **两层进度分层**：`progress[task]` = 任务级（plan cursor）；`completion` = 项目整体验收档（Reviewer
   独立判）——互不覆盖。评审 done 不把任务级 in_progress 顶掉。
3. **处置语义押后**：评审 fail 后"自动重跑未达标任务"属于自管理 loop；本期只判、落档，不调度。

## 二、验收（单测 5 例）

| 用例 | 断言 |
|---|---|
| `pass_writes_completion_done` | 模型返 pass → `project.json.completion.verdict=done`、why 带 feedback、when 非空；**项目简报喂给 Reviewer**（含 目标/自定义验收标准/任务 id） |
| `fail_writes_completion_fail` | 模型返 fail → completion.verdict=fail、why 带"产物没找到"；progress[weekly] 仍 in_progress（任务级不受顶） |
| `criteria_falls_back_to_completion_criteria` | 不传 project_criteria（解析 “null”）→ 简报用 project.completion_criteria（StrictDoD） |
| `missing_model_fails_closed` | 无 m 组件 → verdict=fail、why 提"未配置"；completion 同步 fail（不伪造 pass） |
| `no_review_no_completion` | 无评审节点 → project.json 无 completion 键（第一刀回归） |
