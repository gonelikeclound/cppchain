# cppchain 文档库

> 本文档库的**组织规范**与项目**基调**。开始阅读前请先读完本页。

## 一、文档组织规则

1. `docs/` 下的文件**必须按子目录分类保存**，目前包含（后续可增补）：
   - `01-discuss/` —— 讨论区：项目方向、思路、Agent 理论/想法的探讨
   - `02-arch-design/` —— 架构设计：整体分层、模块划分、核心抽象
   - `03-detail-design/` —— 详细设计：具体模块/组件的内部设计
   - `04-problems/` —— 问题分析：LLM/Agent 开发常见问题 + 方案对比 + demo 验证
2. **目录名与子文件名一律以数字开头**编号，保证有意义的阅读顺序（如 `01-discuss/01-项目基调与构建原则.md`）。
3. 新增文件时继续递增编号；若需在中间插入，允许为保持语义连续而微调后续编号。

## 二、项目基调（摘要）

完整的基调文档见 [01-discuss/01-项目基调与构建原则.md](01-discuss/01-项目基调与构建原则.md)，要点：

- **项目定位**：基于 C++26 的 langchain 与 langgraph 的**简化复刻版**，用于学习大模型与 Agent 开发。
- **构建方式**：沿着 langchain 的思路，**从底部向上、一点一点地构建**；是实验场，不是生产级完整实现。
- **文档主线**：记录 LLM/Agent 开发中的常见问题（上下文压缩、大批量工具查找、超长工具返回、工具副作用、SubAgent/ForkAgent 使用等），对每类问题做分析，并为各种解法提供 **demo 验证**。
