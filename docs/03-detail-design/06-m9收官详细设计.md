## 2. 接口定义

### 2.1 `agent/tokens` —— 无 tokenizer 的启发式

```cpp
namespace cppchain::agent::tokens {
// 字符统计口径：多字节字符（CJK 等）一字≈1 token；ASCII ≈4 字符/token；含尾部取整。
// 单调不减（对前缀长度）→ 供截断的二分回退使用。
std::size_t estimate(std::string_view text);
// 消息序列 = role 开销（~4/条）+ 各 ContentBlock 文本之和
std::size_t estimate_msgs(std::span<message::Message const> msgs);
}
```

### 2.2 `TrimHistory` 扩展（token 触发 + 成本可见）

```cpp
struct TrimHistory::Options {
  std::size_t max_messages = 20;
  std::optional<std::size_t> max_tokens;   // 新增：估算占用上限（设了才按 token 触发）
  Summarizer summarizer;
  VolatilePolicy volatile_policy = VolatilePolicy::Fold;
};

class TrimHistory {
  // 新增只读：摘要次数 / 累计省下的估算 token（= 折叠区间文本 - 摘要文本）
  [[nodiscard]] std::size_t summaries() const;
  [[nodiscard]] std::size_t estimated_tokens_saved() const;
};
```

**触发 + 折叠量算法**（`before_model`）：

```
if msgs.size() <= max_messages && (!max_tokens || estimate_msgs(msgs) <= *max_tokens): return  // 不压
drop = msgs.size() - max_messages
if max_tokens:  // token 超限时加大折叠量，直到存活部分估算不超限
  while (drop < keep_from 的右界 && estimate_msgs(head+存活区) > *max_tokens) ++drop
drop = safe_boundary(msgs, keep_from, drop)   // 边界安全不变式照旧
...（原有折叠/摘要/重建逻辑不动）
tokens_saved_ += estimate_msgs(被折叠文本) - estimate_msgs(摘要文本)
```

**摘要成本**：`Summarizer` 签名不变；真机 budget demo 用自建闭包直接测那次调用的 `usage`。
`TrimHistory` 自己只记 `summaries()` 与估算省量——成本/信息损失两列都可在横向表打印。

### 2.3 `TruncateToolResults`（token 预算截断）

```cpp
struct TruncateToolResults {
  struct Options { std::size_t max_chars = 2000; std::optional<std::size_t> max_tokens; };
  explicit TruncateToolResults(Options opts);   // 新增重载（旧 构造 max_chars 保留）
  void after_tool(Message& tool_message) override;
};
```

- `max_tokens` 未设 → 现有字节截断路径（回归不变）。
- 设置了 → `estimate(text)` 超限时**二分回退**到字符边界：
  ```
  lo=0, hi=text.size()
  while lo<hi: mid=ceil((lo+hi)/2); b=char_boundary(mid)
                estimate(prefix(..b)) <= max_tokens ? lo=b : hi=b-1
  content = prefix(lo) + 标注「已按 token 预算截断（原文 X tokens，截断后保留前 N token）」
  ```
  依赖 2.1 的单调性。

### 2.4 `ToolApproval`（审批记忆化 + 按只读免审）

```cpp
enum class ToolApproval::MemoPolicy { Off, RememberDeny, RememberAll };
struct ToolApproval::Options {
  MemoPolicy memo = MemoPolicy::RememberDeny;
  std::size_t max_entries = 128;                    // FIFO 有界
  tool::ToolRegistry const* registry = nullptr;     // 非拥有；给了才做"只读免审"
};
// 新增构造重载：ToolApproval(std::vector<std::string> denied, Options)
//            ToolApproval(Decider, Options)
```

`approve_tool_call` 流程：
```
if registry && spec = registry->find(call.name) && spec->read_only → 直接放行（不进批准/记忆）
fingerprint = call.name + "|" + canonical_json(call.args)     // 参数键排序后 dump（稳定）
if memo 命中 → memo_hits_++; 返回缓存结论
决策 = 现有 decider/denied 逻辑
按策略记录：deny 永远记；allow 仅 RememberAll 记（RememberAll 才缓存放行）
entries 满 → FIFO 逐出最旧
```

fingerprint 归一化（`canonical_json`）：nlohmann 对象键无序 → 显式按键排序重建再 dump，
保证 `{"a":1,"b":2}` 与 `{"b":2,"a":1}` 同一指纹。

### 2.6 `ArtifactToolResults`（落盘中间件）

```cpp
// agent/artifact.hpp
class ArtifactToolResults final : public Middleware {
 public:
  struct Options {
    std::string dir = "./artifacts";
    std::size_t max_inline_tokens = 40;   // 估算超限才落盘
  };
  explicit ArtifactToolResults(Options opts);
  void after_tool(Message& tool_message) override;
  [[nodiscard]] std::size_t artifacts_written() const;
};
```
- `after_tool`：超内联预算 → 写 `<dir>/artifact_<seq>_<sanitized(tool_call_id)>.txt`（UTF-8 安全截断、
  目录用 `create_directories`；文件名只留 `[A-Za-z0-9_-]` 防路径注入——沿用文件工具沙箱纪律）→
  `content` 换成 **引用行**（前 40 token + 已落盘 size/估算 token + 提示"需要细节可读文件"），
  `artifact = 相对路径`。
- 与 `TruncateToolResults` 的关系：可叠加（截断负责把 inline 压到预算，落盘负责把超预算的全文
  交给文件）；demo 里两者配合展示"prompt 只放引用 + token 下降"。

### 2.7 `HybridSelector`（问题 1 收官）

```cpp
// tool/hybrid_selector.hpp
class HybridSelector final : public ToolSelector {
 public:
  struct Options {
    std::size_t keyword_k = 8;
    std::size_t vector_k = 8;
    bool use_vector = true;                 // 关掉即退化为关键词（对照）
    KeywordSelector::Options keyword{};
  };
  HybridSelector(model::Embeddings* embedder, Options opts);
  std::expected<void, model::ModelError> build_index(ToolRegistry const& reg);  // 转发 EmbeddingSelector
  std::vector<ToolSpec const*> select(ToolRegistry const& reg, std::string_view query, std::size_t k) const override;
};
```
- `select`：`KeywordSelector.select(reg, q, keyword_k)` ∪ `EmbeddingSelector.select(reg, q, vector_k)`
  → 按 `ToolSpec*` 去重 → 超出 `k` 截尾。排序：关键词结果在前（可解释/可复现），向量独家命中的补在后面；
  纳入 `last_error()`（向量查询失败 → 降级纯关键词）。

## 3. 关键算法与契约

1. **估算单调性**：`estimate` 对前缀长度**非降** → 二分回退合法；单测显式断言前缀单调。
2. **默认行为不变**：三件套的既有构造/字段语义 = 新增 option 的缺省值；让步是"加字段加重载"，
   不是"改语义"——259 既有测试全绿是回归门槛。
3. **审批/防重放分两本账**（延续 M8 契约）：记忆化省审批开销、Journal 防副作用重放；
   `ArtifactToolResults` 只**读**文件（不改外部状态，read_only 语义不因此变化）。
4. **有界**：memo `max_entries` FIFO；落盘文件名 seq 单调；`tokens_saved_` 只在压缩发生时累加。
5. **只读免审是显式开关**：`registry` 缺省 `nullptr` → 行为与现在完全一致（不隐式改变对既有调用方）。

## 4. 测试点（离线确定性优先）

- `tokens_test`：纯 ASCII / 中文 / 混合 / 空；前缀单调性（二分前提）。
- `trim_token_test`：条数未超而 token 超 → 触发；折叠后估算 ≤ 阈值；边界安全（孤儿 ToolMessage 修正）仍成立；`estimated_tokens_saved` 正确累加（折叠区间-摘要）。
- `truncate_token_test`：token 预算截断不切断 UTF-8、落在预算内、`max_chars` 路径回归（旧测试继续绿）。
- `approval_memo_test`：RememberDeny 同指纹二次直接拒（`memo_hits≥1`、denials 增加一次）；
  RememberAll 放行也缓存；Off 无记忆；不同参数不同指纹；FIFO 有界；`registry` 给定时只读工具免审。
- `artifact_test`（message + middleware）：`Message.artifact` round-trip；
  落盘文件存在且内容=原文、content 变引用行、`artifacts_written` 计数、短结果不落盘。
- `hybrid_selector_test`：fake embedder 下三种组合（keyword-only / vector-only / hybrid）的 union-去重；
  向量失败降级关键词；`last_error` 置位。
